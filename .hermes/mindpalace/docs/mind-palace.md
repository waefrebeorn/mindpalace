# Mind Palace — Canon Structure

Mind Palace is a prestige prompt structure. It is not a shortcut.
It is a discipline.

## Core properties

- Prestige — only high-signal payloads are promoted.
- Multi-stage — work is divided into ordered stages.
- Deterministic — given the same seed, the same path is taken.
- Loopable — loops can terminate early, be truncated, or be resumed.
- Ephemeral — the 1000-step list is regenerated if it diverges.

## Branch-first load rule

All implementations must branch from an existing branch in this repo.
No branch is created without a parent.

## The four permitted moves

1. Load — bring a branch into context.
2. Index — update the project-wide file index.
3. Scaffold — generate a new stage or phase skeleton.
4. Review — run the 4-phase loop on a target.

## Question authority

Nothing is authoritative unless it is in this folder.
If there is a conflict, the more populated branch wins.
