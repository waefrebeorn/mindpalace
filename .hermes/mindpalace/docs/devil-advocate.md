# Devil’s Advocate — Four-Phase Loop

The four-phase loop is the Mind Palace’s explicit adversarial structure.
It is never condensed. It is never abbreviated. The four phases are
always present and always in this order.

## Phases

1. **Locate** — identify the subject, scope, and success criteria.
2. **Argue AGAINST** — produce the strongest possible negative case.
3. **Argue FOR** — produce the strongest possible positive case.
4. **Decide** — synthesize, select a direction, record rationale.

## State machine

```
LOCATE -> AGAINST -> FOR -> DECIDE -> REPEAT or DONE
```

Each run of the loop is one **devils pass**.
Multiple devils passes across stages form the **devils cycle**.

## Output fields

- `phase`
- `pass`
- `claim`
- `evidence`
- `confidence`
- `decision`

## Anti-patterns

- Skipping FOR because AGAINST is “obviously correct”.
- Bypassing DECIDE because AGREE was reached early.
- Confating multi-issue subjects with single-issue subjects.
- Re-running against evidence that has already been re-scoped.
